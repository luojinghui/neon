## Why

Neon 目前缺少一个轻量、公开的生活动态入口，用户无法在首页或个人中心记录当下，也无法浏览其他人的近况。需要新增与现有星球视觉语言一致的“心迹”，承载文字、媒体、语音和位置，并提供可控的评论互动。

## What Changes

- 首页新增“心迹”入口，并提供按发布时间倒序排列的公共时间流
- 用户可从心迹页或自己的个人中心发布文字、图片、视频、语音与 H5 位置
- 心迹支持平铺评论和回复，默认展示最新 2 条并可展开全部
- 评论作者可编辑、删除自己的评论；超级管理员可删除任意评论
- 心迹作者与超级管理员可删除整条心迹，并级联删除媒体和评论
- 个人中心以“资料”为默认页签、“心迹”为第二页签，以方格和轮播查看个人全部心迹
- 为心迹数据和媒体提供文件持久化、部署目录配置及自动化测试

## Capabilities

### New Capabilities

- `moments`: 心迹发布、公共时间流、评论互动、权限控制与个人心迹画廊

### Modified Capabilities

- `profile`: 个人中心增加心迹页签、发布入口和轮播查看
- `home-navigation`: 首页与 PWA 快捷入口增加心迹
- `admin-user-management`: 删除人员时清理其心迹数据

## Impact

- 新增 `/moments` 页面及 `/api/moments/**` API
- 修改首页、PWA manifest、个人中心和超管人员删除流程
- 新增 `.data/moments.json` 与 `public/uploads/moments`，生产环境可通过环境变量外置
- 不引入新的 npm 依赖，继续使用现有 Next.js、React、Ant Design 与文件存储方案
